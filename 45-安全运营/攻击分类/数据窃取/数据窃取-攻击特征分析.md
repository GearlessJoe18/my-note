## 告警优先级

### 高优先级关注

已确认敏感数据打包、外传或异常下载的行为，应优先核验网络、文件与账号证据。

### 中高优先级关注

异常压缩、批量读取、可疑外联或云存储访问需结合资产与时间线判断。

### 辅助研判类

缺少响应、流量或文件证据时，仅能判断为尝试或证据不足。

# 数据窃取攻击特征分析

> 所属：[[攻击分类索引]]
> 定位：数据窃取攻击特征分析

日期：2026-08-04
主题：数据窃取类告警总结

## 结论

数据窃取的本质是：攻击者在获得文件访问、系统权限、数据库权限、WebShell、命令执行或漏洞读取能力后，尝试读取、下载、打包、导出或外传目标系统中的资料文档、系统密码、配置文件、系统文件、数据库数据和代码文件，从而获取账号凭据、业务数据、源码逻辑、密钥和后续攻击线索。

## 本批告警概览

数据窃取类：

- 资料文档窃取
- 系统密码窃取
- 配置文件窃取
- 系统文件窃取
- 通用数据库数据窃取
- 代码文件窃取
- 密码窃取工具
- SQL Server 数据窃取

## 数据窃取是什么

数据窃取是攻击链中后期常见行为。攻击者通常已经具备某种访问能力，例如：

- 目录遍历或任意文件读取
- WebShell 连接
- 系统命令执行
- 后台登录成功
- 数据库账号可用
- 弱口令登录成功
- 未授权访问
- 主机权限或服务账号权限

获得访问能力后，攻击者会尝试找到有价值的数据，并将其读取、复制、下载、导出、压缩或外传。

## 数据窃取的共同点

数据窃取类告警的共同点是：

- 目标都是敏感数据或可用于后续攻击的信息
- 通常发生在攻击者已经获得某种访问入口之后
- 不一定每次都代表外传成功，需要结合响应、文件访问、数据库审计和流量判断
- 配置文件、系统密码和代码文件经常会成为后续横向移动和权限扩大线索
- 数据库数据和资料文档一旦泄露，通常会产生直接业务影响

## 攻击具体行为总结

数据窃取类行为可以概括为：

> 攻击者通过文件读取漏洞、WebShell、命令执行、数据库连接、后台权限、未授权访问或弱口令登录，访问目标系统中的文档、密码、配置、系统文件、数据库数据和源码，并尝试读取、下载、导出、打包或外传这些敏感信息。

## 行为分类

| 告警类型 | 具体行为 | 怎么成功 | 攻击者可能获得什么 |
|---|---|---|---|
| 资料文档窃取 | 读取、下载、打包或外传办公文档和业务资料 | 攻击者已获得文件访问权限、后台权限或主机访问能力 | 合同、报表、客户资料、内部文档、业务数据 |
| 系统密码窃取 | 读取系统凭据、密码文件、Hash、Token 或密钥 | 攻击者具备高权限文件访问、凭据读取或命令执行能力 | 系统账号、密码 Hash、SSH key、Token、认证凭据 |
| 配置文件窃取 | 读取应用配置、数据库配置、环境变量文件 | Web 目录泄露、目录遍历、WebShell、主机权限或源码泄露 | 数据库连接串、账号密码、API Key、云密钥、服务地址 |
| 系统文件窃取 | 读取操作系统关键文件、日志或认证文件 | 文件读取漏洞、WebShell、主机权限或未授权访问 | 系统信息、用户信息、认证线索、运行环境信息 |
| 通用数据库数据窃取 | 查询、导出或下载数据库数据 | 数据库账号泄露、SQL 注入、后台权限、数据库暴露 | 用户表、订单、业务数据、敏感字段 |
| 代码文件窃取 | 读取源码、脚本、仓库文件或代码压缩包 | 源码目录暴露、备份泄露、WebShell、Git 泄露或文件读取 | 业务逻辑、接口信息、密钥、漏洞线索、知识产权 |
| 密码窃取工具 | 使用工具抓取或导出凭据 | 工具被执行并能访问凭据位置、内存或浏览器数据 | 浏览器密码、系统凭据、Hash、Token、Cookie |
| SQL Server 数据窃取 | 针对 SQL Server 查询、导出或读取数据 | SQL Server 弱口令、账号泄露、SQL 注入或权限滥用 | 数据库表、账号、业务数据、配置数据 |

## 一次数据窃取可能怎么完成

常见链条一：配置泄露到数据库数据窃取

```text
目录遍历 / 任意文件读取
-> 配置文件窃取
-> 获得数据库账号密码
-> 连接数据库
-> 查询或导出敏感表
-> 数据外传或继续横向移动
```

常见链条二：WebShell 到文件窃取

```text
WebShell 连接
-> 执行目录枚举命令
-> 查找文档、配置、源码、备份文件
-> 打包压缩
-> 下载或外传文件
```

常见链条三：系统密码窃取到权限扩大

```text
命令执行 / 主机权限
-> 读取系统凭据或密码文件
-> 获取账号、Hash、SSH key、Token
-> 尝试登录其他主机或服务
-> 横向移动或提升权限
```

## 怎么判断数据窃取成功

可以判断成功或高度疑似成功的证据包括：

- 响应中返回真实文件内容
- Web 日志显示敏感文件被下载且状态码为成功
- 文件访问日志显示大量读取文档、配置、源码或数据库备份
- 数据库审计日志显示异常查询、导出、大量读取
- 主机出现压缩、打包、复制敏感目录的命令
- 网络流量显示大体量上传或连接异常外部地址
- DLP、网关或代理日志记录到敏感文件外传
- 攻击者访问的文件包含密码、密钥、Token、连接串或业务数据

只能判断为尝试或证据不足的情况包括：

- 只有告警名称，没有响应内容
- 只有请求敏感文件，没有返回包
- 只有状态码 200，但不知道是否是统一错误页
- 只有“数据窃取”规则命中，没有文件名、大小和方向
- 只有数据库连接告警，没有查询内容和返回量
- 只有文件访问记录，没有确认是否被外传

## 攻击者可能获得了什么

数据窃取成功后可能获得：

- 业务资料和内部文档
- 用户数据、客户数据、订单数据
- 数据库账号、密码和连接串
- 系统账号、Hash、SSH key、Token、Cookie
- 应用源码、接口逻辑和漏洞线索
- 日志文件、系统路径、主机信息
- 云服务密钥、第三方 API Key
- 内网资产和服务信息
- 后续登录、横向移动或权限提升线索

## 当前这批告警的观察点

从数量看：

- 资料文档窃取数量较高，需要重点确认是否有真实文件下载和外传
- 系统密码窃取风险高，可能导致账号泄露、横向移动和权限扩大
- 配置文件窃取风险高，因为配置中常见数据库连接串、账号密码、Token 和密钥
- 系统文件窃取需要确认读取的是普通系统信息，还是认证、账号、日志等敏感文件
- 通用数据库数据窃取和 SQL Server 数据窃取需要结合数据库审计确认查询内容、账号和数据量
- 代码文件窃取可能暴露源码、密钥和业务逻辑，应结合仓库、Web 目录和备份文件排查
- 密码窃取工具数量可能不高，但告警语义高危，需要确认工具是否执行成功、读取了哪些凭据

## 安全运营看数据窃取告警的方法

### 1. 先判断数据类型

```text
资料文档 / 系统密码 / 配置文件 / 系统文件 / 数据库数据 / 代码文件 / 凭据工具输出
```

不同数据类型对应不同影响。配置、密码、数据库、源码通常优先级更高。

### 2. 看访问入口

关注攻击者是通过什么方式访问数据：

- 目录遍历
- 任意文件读取
- WebShell
- 系统命令执行
- 后台登录
- 数据库账号
- 未授权访问
- 弱口令登录

### 3. 看文件和数据证据

关注：

- 文件路径
- 文件名和后缀
- 文件大小
- 响应内容
- 下载状态码
- 数据库表名
- 查询语句
- 返回行数
- 是否包含密码、密钥、Token、连接串或业务数据

### 4. 看账号和权限

关注：

- 谁访问了文件或数据库
- 使用了哪个账号
- 账号是否异常
- 是否为服务账号、后台账号、数据库账号或系统账号
- 是否越权访问了不该访问的数据

### 5. 看网络方向

关注：

- 是否从内部上传到外部
- 是否连接云存储、匿名文件站、可疑 IP 或域名
- 是否存在大流量外传
- 是否传输了压缩包、数据库导出文件、源码包或文档包

### 6. 看时间线

重点看是否形成链条：

```text
配置文件窃取 -> 获得数据库密码 -> 数据库登录 -> 数据库数据窃取
```

或者：

```text
WebShell 命令执行 -> 打包文档目录 -> 下载压缩包 -> 外联传输
```

## 常见研判结论模板

### 资料文档窃取

> 发现目标资产存在疑似资料文档窃取行为，攻击者可能访问、下载或打包业务文档。当前需确认访问文件路径、文件类型、响应大小、下载源 IP、账号信息和是否存在外传流量。仅凭告警名称不能确认数据已泄露，需结合文件访问日志和网络传输证据判断。

### 配置文件窃取

> 发现目标资产存在疑似配置文件窃取行为，攻击者可能尝试读取应用配置、环境变量、数据库连接串或密钥文件。当前需确认响应是否返回真实配置内容，是否包含账号密码、Token、密钥或连接串，并排查后续数据库访问、后台登录和横向移动行为。

### 系统密码窃取

> 发现目标主机存在疑似系统密码窃取行为。当前需核验触发进程、访问文件、执行账号、是否读取凭据存储、Hash、Token、SSH key 或浏览器密码，并确认是否出现异常登录、横向移动或凭据复用行为。

### 系统文件窃取

> 发现目标主机存在疑似系统文件窃取行为。当前需确认被访问文件路径、文件内容敏感性、访问账号、访问来源、响应内容和后续行为。若涉及认证文件、账号文件、日志或关键配置，应提高风险等级并排查是否存在进一步利用。

### 数据库数据窃取

> 发现目标数据库存在疑似数据窃取行为。当前需结合数据库审计日志确认访问账号、来源地址、查询语句、导出操作、返回数据量和访问表名。若存在大批量查询、敏感表导出或异常账号访问，应按高危数据泄露事件处置。

### 代码文件窃取

> 发现目标资产存在疑似代码文件窃取行为，攻击者可能访问源码、脚本、仓库文件或代码备份包。当前需确认文件路径、响应内容、下载大小、是否包含密钥或配置，并排查后续漏洞利用、账号登录或代码泄露影响。

### 密码窃取工具

> 发现目标主机存在疑似密码窃取工具行为。当前需确认工具文件、执行账号、进程链、命令行、访问的凭据位置、输出文件和后续登录行为。仅凭工具告警不能确认凭据已被成功窃取，需结合执行结果和后续认证日志判断。

## 研判

> 该告警表现为目标资产存在疑似数据窃取行为，攻击者可能已经具备文件访问、命令执行、数据库访问、后台权限或未授权访问能力，并尝试读取资料文档、系统密码、配置文件、系统文件、数据库数据或代码文件。当前需结合响应内容、文件访问日志、数据库审计、账号信息、主机日志、网络流量和后续行为判断是否窃取成功、具体泄露了哪些数据，以及是否发生外传或横向移动。

## 当前记录中的不确定内容

- 只有告警名称和数量，不能确认每条告警是否成功
- 不能确认资料文档是否真实被下载或外传
- 不能确认系统密码、配置文件、系统文件具体泄露了哪些内容
- 不能确认数据库数据窃取涉及哪些库表、账号和数据量
- 不能确认代码文件是否包含密钥、凭据或核心业务逻辑
- 不能确认密码窃取工具是否执行成功、是否获得有效凭据
- 不能确认是否发生数据外传、横向移动或凭据复用
- 需要结合响应包、Web 日志、文件访问日志、主机日志、数据库审计、网络流量和资产归属进一步判断

## 学习重点

- 数据窃取关注“攻击者拿走了什么”
- 配置文件、系统密码和数据库数据一旦泄露，可能引发后续横向移动
- 资料文档和业务数据泄露会产生直接业务影响
- 代码文件泄露可能暴露密钥、接口、业务逻辑和后续漏洞线索
- 判断数据窃取是否成功，要看响应内容、文件访问、数据库审计和外传流量
- 只有告警命中不等于数据已泄露
- 不确定内容必须明确标注，不能把“疑似窃取”直接写成“数据已泄露”
