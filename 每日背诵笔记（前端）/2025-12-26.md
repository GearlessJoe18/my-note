### 对象中函数简写
```javascript
// 【传统写法】ES5 及之前
const person = {
  name: '张三',
  add: function(a, b) {
    return a + b;
  }
};

// 【ES6 简写写法】（推荐）
const person = {
  name: '张三',
  add(a, b) {
    return a + b;
  }
};

// 调用方式完全一样
console.log(person.add(1, 2)); // 输出：3
```

$event.target.value

`$event` 是浏览器为这个输入框的 `input` 事件生成的**专属事件对象**，其中 `target` 属性固定指向 “触发这个事件的那个 DOM 元素”—— 也就是当前这个输入框本身，再通过 `value` 属性就能拿到它的内容。
