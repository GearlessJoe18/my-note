在 Vuex 中，`actions` 里的处理函数（动作函数）**核心接收两个参数**：

第一个是包含 Vuex 上下文的对象（可解构出 `commit`、`state` 等）

第二个是用户传递的自定义载荷（payload）

```js
actions: {
  // 完整写法（上下文对象 + 载荷）
  动作名(context, payload) {
    // context: 上下文对象，包含 Vuex 核心方法/属性
    // payload: 调用动作时传递的参数（可选）
  },

  // 解构写法（常用，直接提取需要的属性）
  动作名({ commit, state, getters, dispatch, rootState, rootGetters }, payload) {
    // 解构后可直接使用 commit、state 等
  }
}
```

| 属性 / 方法       | 作用说明                                                            |
| ------------- | --------------------------------------------------------------- |
| `commit`      | 触发 mutations 中的方法（唯一能修改 state 的方式），格式：`commit('mutation名', 载荷)` |
| `state`       | 当前模块的 state（如果是根模块，就是根 state；如果是命名空间模块，就是当前模块的 state）           |
| `getters`     | 当前模块的 getters（命名空间模块下仅能访问当前模块的 getters）                         |
| `dispatch`    | 触发其他 actions（可触发当前模块 / 其他模块的动作），格式：`dispatch('action名', 载荷)`    |
| `rootState`   | 根模块的 state（命名空间模块中访问根 state 时使用）                                |
| `rootGetters` | 根模块的 getters（命名空间模块中访问根 getters 时使用）                            |
