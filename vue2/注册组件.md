
```vue
<script>
import HelloWorld from './components/HelloWorld.vue';
import ButtonCounter from './components/ButtonCounter.vue';

export default {
  // 核心：{} 包裹的对象，键是组件名，值是组件对象
  components: {
    // 写法1：ES6 简写（键和值同名）
    HelloWorld, 
    // 写法2：完整键值对（自定义组件名）
    'button-counter': ButtonCounter
  }
};
</script>
```

必须用{}包裹，键值对，key是用的标签名，value是dao
